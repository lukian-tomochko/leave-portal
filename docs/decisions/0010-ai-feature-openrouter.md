# 0010. Помічник календаря (зріз 4): AI SDK + OpenRouter (безкоштовні моделі) + zod

- Статус: прийнято
- Дата: 2026-11-16
- AC: AC-ASSIST-01, AC-ASSIST-05, AC-ASSIST-06, AC-ASSIST-07, AC-ASSIST-09, AC-ASSIST-10

## Контекст

Зріз 4 додає AI-функцію: адміністратор вставляє текст шкільного календаря (до 2000 символів), помічник пропонує
закриття, адміністратор перевіряє, редагує й зберігає їх сам (вимога PM `05-calendar-assistant.md`). Обмеження:

- Next.js 16.4 на Vercel Hobby; Server Action приймає тіло до 1 МБ, нам достатньо 2000 символів.
- Модель — безкоштовна через OpenRouter, ключ власний. Ліміт безкоштовних моделей — 20 запитів/хв і 50/день на акаунт;
  додаткові ключі ліміту не збільшують, його ділять eval, UAT і приймання PM. Безкоштовні моделі з'являються й зникають.
- Безкоштовні ендпоінти можуть зберігати й використовувати запити для навчання: лише синтетичні тексти.
- Відповідь моделі недетермінована, а CI має бути без мережі й без секретів.

## Рішення

- Нові залежності (точні версії): `ai@7.0.162`, `@openrouter/ai-sdk-provider@3.1.0`, `zod@4.6.7`, `server-only@0.0.1`.
- Виклик — `generateText` + `Output.object({ schema })` (AI SDK 7). Схема zod у `src/lib/ai/schema.ts` має стан
  `status: ok | needs_info | refused`; «невідоме» = `null`.
- Чиста функція `suggestClosures(text, today, model)` не читає `process.env`: модель — параметр; ключ читає лише
  `src/lib/ai/openrouter.ts` з `import "server-only"` (змінна `OPENROUTER_API_KEY`, без `NEXT_PUBLIC_`; немає ключа → `null`).
- Ланцюжок моделей лише `:free`: `google/gemma-4-31b-it:free` → `google/gemma-4-26b-a4b-it:free` →
  `nvidia/nemotron-3.5-super-vl:free`.
- Людина в контурі: `requestSuggestions` лише повертає пропозиції й нічого не пише; `saveSuggestions` — окрема дія
  адміністратора з `getClaims()`, роллю, повторною валідацією і записом наявною `add_school_closure` під його сесією.
- Якість: 10 golden cases PM. Офлайн-реплей записаних відповідей (`MockLanguageModelV4`) — у `npm test`; живий прогін —
  `npm run eval` вручну зі звітом у `evals/reports/`.

## Розглянуті варіанти

- Claude Agent SDK у функції Vercel — ні: підпроцес Claude Code завеликий для пакета функції, а потрібен один виклик моделі.
- Пакет `openai` з `baseURL` OpenRouter або `@openrouter/sdk` — ні: немає валідації схемою з типізованими помилками й
  тестових моделей в одному API.
- `openrouter/free` (випадкова безкоштовна модель) — ні: результат golden cases не відтворюється.
- Платний ключ — ні: курс використовує безкоштовні моделі; перехід — заміна однієї фабрики в `src/lib/ai/models.ts`.

## Наслідки

- Провайдера й модель міняємо в одному файлі; CI не залежить від мережі та ліміту.
- Безкоштовна модель може зникнути або впертися в ліміт: інтерфейс показує дослівне «unavailable» з AC-ASSIST-09, ручне
  додавання закриття працює незалежно. Ланцюжок перевіряємо `npm run ai:models`.
- `tests/fixtures/golden/recorded.json` треба оновлювати (`RECORD=1 npm run eval`), коли змінюється промпт
  (`CALENDAR_PROMPT_VERSION`) або схема.

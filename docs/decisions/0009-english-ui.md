# 0009. Інтерфейс повністю англійською

- Статус: прийнято; замінює правило мови з `DESIGN.md` §3 («інтерфейс українською, тексти PM англійською») і частково 0008
- Дата: 2026-11-13
- AC: AC-LEAVE-06, AC-LEAVE-18, AC-BALANCE-08, AC-DECIDE-14, AC-CAL-03

## Контекст

До цього рішення інтерфейс був змішаний: тексти й назви з вимог PM (AC, статуси, типи відпусток, заголовки таблиць) англійські й перевіряються
автотестами дослівно, а решту (кнопки, підписи, заголовки, місяці) розробник писав українською за мовою шаблону курсу. Це давало неоднорідний
вигляд: у одному екрані «Awaiting decision» і «Нова заявка». Власник продукту вирішив зробити інтерфейс повністю англійським.

## Рішення

- Усі видимі користувачу тексти (кнопки, мітки, заголовки, підказки, повідомлення без тексту PM, `aria-label`, `title` сторінок) — англійською. Тексти PM не змінюються.
- `lang="en"`; назви місяців і днів тижня англійські (`MONTHS`, `WEEKDAYS`, `dayLabel` → «13 Nov»); `SCHOOL_MONTHS` — Sep…Aug; `localeCompare(..., "en")`.
- Локаль Playwright — `en-US` (часовий пояс `Europe/Kyiv` лишається, бо дати київські).
- Коментарі в коді, документація, описові назви тестів і відповіді агента лишаються українською (`CLAUDE.md`). Дані в базі (імена тощо) не змінюються;
  шрифти з підмножиною `cyrillic` лишаються для таких даних.
- Локатори E2E/UAT переписано на англійські мітки; описові речення `visible:` для рецензента UAT, що цитують інтерфейс, виправлено.

## Розглянуті варіанти

- **Лишити змішану мову.** Нічого не міняти, але вигляд неоднорідний. Відхилено власником.
- **Словник uk/en з перемикачем.** Дає обидві мови, але подвоює тексти й тести й ускладнює перевірку на розбіжності. Відхилено як зайве на цьому етапі.

## Наслідки

- Один набір текстів: тести стабільніші, повідомлення PM і решта в одній мові.
- Українські користувачі втрачають рідну мову інтерфейсу; якщо вона знадобиться, це нове рішення зі словником і перемикачем.
- Історичні звіти `docs/qa/uat/*` цитують старий український інтерфейс; це записи, їх не редагуємо.

## Як перевіряємо

- `npm run lint`, `typecheck`, `npm test`, `npm run build`; пошук кириличних рядків у JSX і літералах `src/` поза коментарями.
- E2E/UAT після зміни локаторів запускає власник.

# Дельта: school-calendar

## ADDED Requirements

### Requirement: Кілька перетинів в одному повідомленні

IF нове закриття перетинається з кількома наявними закриттями, THEN the system SHALL не зберегти нове закриття й показати повідомлення з однією частиною "<дата> is already closed: <назва закриття>" на кожне наявне закриття з його першою спільною датою, у порядку дат через ", ".

#### Scenario: AC-CAL-17 Новий діапазон зачіпає два закриття

- **GIVEN** "Winter break" 2026-12-28 – 2027-01-08 і "Staff day" 2027-01-12
- **WHEN** адміністратор намагається додати "Extra break" з 2027-01-05 до 2027-01-15
- **THEN** закриття не збережено
- **AND** адміністратор бачить повідомлення "2027-01-05 is already closed: Winter break, 2027-01-12 is already closed: Staff day"

### Requirement: Назва закриття обов'язкова

IF адміністратор залишає назву закриття порожньою, THEN the system SHALL не зберегти закриття й показати повідомлення "Enter a name for the closure".

#### Scenario: AC-CAL-18 Порожня назва

- **GIVEN** адміністратор додає закриття на 2027-01-20
- **WHEN** адміністратор залишає назву порожньою й намагається зберегти
- **THEN** закриття не збережено
- **AND** адміністратор бачить повідомлення "Enter a name for the closure"

### Requirement: Довжина назви закриття

IF назва закриття довша за 100 символів, THEN the system SHALL не зберегти закриття й показати повідомлення "The name can be at most 100 characters".

#### Scenario: AC-CAL-19 Назва зі 101 символу

- **GIVEN** адміністратор додає закриття на 2027-01-20
- **WHEN** адміністратор вводить назву зі 101 символу й намагається зберегти
- **THEN** закриття не збережено
- **AND** адміністратор бачить повідомлення "The name can be at most 100 characters"
